# Лабораторная работа №5: Элементы сетевого программирования (Windows Sockets)

## 1. Общие сведения
* **Дисциплина:** Операционные среды и системное программирование (ОСиСП).
* **Вариант:** №22 — «TCP Echo Server» (Раздел Г: Стандартные сетевые службы).
* **Спецификация стандарта:** RFC 862 (Echo Protocol).
* **Транспортный протокол:** TCP (SOCK_STREAM, IPPROTO_TCP).
* **Индивидуальные параметры:**
  * `STUDENT_ID = 95`
  * `SEED = 1000 + 95 * 97 = 10215`
  * `BASE_PORT = 20000 + 95 = 20095`

## 2. Архитектура и возможности решения
Комплекс состоит из двух независимых приложений:
1. **`Server.exe` (Многопоточный TCP Echo Server):**
   * Обслуживает произвольное количество клиентов одновременно (минимум 3 клиента в отдельных потоках).
   * Реализует стандарт RFC 862: возвращает принятые байты клиенту без какой-либо модификации.
   * Полная бинарная прозрачность: передача любых данных, включая нулевые байты `0x00`.
   * Защита от зависаний через тайм-ауты `SO_RCVTIMEO` и `SO_SNDTIMEO`.
   * Устойчивость к аварийным разрывам клиентов (`WSAECONNRESET` / код 10054).
2. **`Client.exe` (Клиент и бенчмарк-стенд):**
   * Параметризация из консоли: `--host`, `--port`, `--id`, `--size`, `--cycles`, `--timeout`, `--chunked`, `--benchmark`.
   * Генерация детерминированных бинарных массивов на основе SEED с явной вставкой нулей `\0`.
   * Принудительное тестирование фрагментации (отправка неровными кусками по 333 байта).
   * Побайтовая сверка каждого ответа (`memcmp`).
   * Встроенный бенчмарк для автоматического снятия экспериментальных данных.

## 3. Сборка проекта
В среде Microsoft Visual Studio 2019/2022 открыть решение `LW5.sln` и выполнить сборку (`Ctrl+Shift+B`).
Будут собраны два исполняемых файла: `Server.exe` и `Client.exe`.

## 4. Порядок запуска
1. Запуск сервера:
   ```cmd
   Server.exe --host 127.0.0.1 --port 20095 --timeout 15000
   ```

2. Запуск одновременного тестирования 3 клиентов:
   ```cmd
   start Client.exe --id 1 --size 4096 --cycles 500 --chunked
   start Client.exe --id 2 --size 4096 --cycles 500 --chunked
   start Client.exe --id 3 --size 4096 --cycles 500 --chunked
   ```

3. Запуск полного бенчмарка для отчета:
   ```cmd
   Client.exe --benchmark
   ```

4. Построение графиков:
   ```cmd
   python scripts/plot_graphs.py
   ```
